# Editorial Design

Use existing Speech LLM Radar and turn-taking posts for site conventions. Use Puneet Mathur's architecture explainer for the progression from terminology to mechanisms, and Fullduplex's digest for linking observations to primary evidence. Write an original problem-driven synthesis rather than paraphrasing another blog's narrative.

The central problem is choosing a context-appropriate action while listening and speaking concurrently. Present 21 core papers in three compact inventories, then analyze timing supervision, state and playback consistency, asynchronous delegation, and evaluation blind spots. Keep older foundational work outside the recent count.

All reported measurements are paper-author results. Avoid a cross-paper leaderboard because protocols, models, hardware, and denominators differ. Pin versioned links where a title or interpretation changed. Record search scope and exclusions in a research note outside the public source tree.

# Publication

Use the existing Hexo checks and `.deploy_publish` Pages clone. Preserve unrelated untracked files and private material. Add `Codex-Authored: true` to publication commits. Verify the public permalink after pushing.
